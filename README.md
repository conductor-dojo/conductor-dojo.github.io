# Conductor道場

自分のキーマップ JSON を読み込んで、その配列のままタイピングを練習するサイト。

- 盤面の形（40キー・左右分離・右親指のトラックボール）は共通のものとして描く
- 次に押すキーと、押さえておくレイヤーキーが盤面で光る
- キーマップから読むのは**各キーの中身**だけ
- 日本語（ローマ字入力）。shi / si / ci どの流儀でも通る
- 等級ごとのベストタイムが順位表に並ぶ（Firestore・匿名ログイン）
- キーマップはどこにも送らない。ブラウザの中だけで読む

ローカルで見る:

    node serve.js   # http://localhost:8733

仕様と決定ログは SPEC.md。
