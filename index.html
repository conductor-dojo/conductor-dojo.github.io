Keymap Dojo

自分のキーマップで、タイピングを練習する。

キーマップの JSON を置くと、その配列のまま盤面を描いて出題します。 次に押すキーと、押さえておくレイヤーキーが光るので、覚える前から打てます。 アップロードはしません — ファイルはこのブラウザの中だけで読みます。

キーマップの .json をここにドロップ または まず触ってみるなら サンプルのキーマップで試す

対応しているのは ZMK 用キーマップエディタが書き出す JSON（layers[].bindings を持つ形）です。 左右分離・レイヤー・mod-tap・layer-tap を読みます。

配線を流れてくるキーキャップを1枚ずつ打ち切って、40キーぜんぶを盤面に書き込みます。時間制限はありません。落ちる皿は無いので、詰まったら止まって考えて大丈夫です。難しさは 梅 → 竹 → 松 の三段。記録は40キー書き込むまでの時間です。

キーキャップの色は自動で決まります

オレンジ＝レイヤーを出すキー（layer-tap / momentary / toggle）、グレー＝いちばん下の段、それ以外はアイボリー。読み込んだキーマップから機械的に振り分けています。

次のキーと、押さえるレイヤーが光ります

塗りつぶし＝次に押すキー。太枠＝そのあいだ押さえておくレイヤーキー。Shift が要るときは反対の手側の Shift が光ります。

時間制限はありません

キーキャップは右から流れてきて真ん中で止まり、打ち切るまで待ちます。落ちないので、詰まったら盤面を見て考えて大丈夫。記録は全キーを書き込むまでの時間です。

打ち込み窓で「届いているか」が分かる

枠が銅色に光っていれば打鍵はこのページに届いています。灰色なら窓をクリック。日本語IMEがONだと打っても何も出ないので、そのときは直接入力へ。

日本語はローマ字で打ちます

し＝shi / si / ci、ちゃ＝cha / tya / cya、っか＝kka / xtuka — どの流儀でも通ります。配列に無い文字を含む語は出題から外します。

右親指の先はトラックボール

右手の下段は Enter かな の次がボール。Bksp Del はその向こう側なので、下段が左右で 6キー / 4キー と非対称になっています。盤面の形はどの板も同じ前提で、キーの中身だけをキーマップから読んでいます。

ファイルはこのブラウザの中だけ

キーマップはどこにも送りません。記録もこの端末の中だけに残ります。
